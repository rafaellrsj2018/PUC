# PUC | Apoio à disciplina

Este repositório reúne e mantém atualizados conteúdos relacionados à disciplina de pós-graduação. Ele também serve de apoio para preparar atividades, dinâmicas em aula e atividades avaliativas.

## Organização

- `memory-bank/contexto.md`: contexto conhecido do repositório, seu objetivo e orientações para mantê-lo atualizado.
- `materiais/`: sugestão para materiais de aula, referências e anotações organizadas por tema ou encontro.
- `atividades/`: sugestão para instruções, recursos e planos de atividades e dinâmicas.
- `avaliacoes/`: sugestão para enunciados, critérios e materiais de apoio às avaliações.

As pastas de materiais, atividades e avaliações podem ser criadas conforme o conteúdo for sendo reunido.

## Atualização

Ao adicionar conteúdo, registre o tema e, quando disponível, a data, a fonte e a relação com a disciplina. Diferencie informações fornecidas pela disciplina de sugestões preparadas como apoio. Para atividades avaliativas, use os critérios e orientações oficiais quando estiverem disponíveis.

Consulte o [contexto do repositório](memory-bank/contexto.md) antes de ampliar ou reorganizar o material.
